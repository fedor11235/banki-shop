# Banki.shop — тестовое задание

Страница интернет-магазина: каталог товаров с поиском, корзиной и карточкой товара.

## Стек

- **Vue 2.7** (Options API) + **TypeScript**
- **Webpack 5** (сборка, dev-сервер)
- Без UI-библиотек — вёрстка и компоненты написаны с нуля

Конфигурация сборки совместима с **Node.js 16+**.

## Запуск

```bash
# установка зависимостей
npm install

# режим разработки (http://localhost:8081)
npm run dev

# продакшен-сборка в dist/
npm run build
```

Готовую сборку из `dist/` можно открыть любым статическим сервером, например:

```bash
npx serve dist
```

## Функционал

1. **Строка поиска** — фильтрация карточек по названию позиции по мере ввода; лишние карточки скрываются, при пустом результате показывается заглушка «Ничего не найдено».
2. **Кнопка «Купить»** — при нажатии переходит в состояние «Обрабатывается…» (preloader icon) на 2 секунды, затем — «В корзине» (checked icon). Повторный клик по «В корзине» убирает товар из корзины.
3. **Сохранение состояния** — список позиций в корзине хранится в `localStorage` и переживает перезагрузку страницы.
4. **Карточка товара** — по клику на название или изображение открывается модальное окно: краткое описание, цена, слайдер с 3 изображениями (стрелки + точки-индикаторы), закрытие по крестику, клику по подложке или `Esc`.

Вёрстка адаптивная, вплоть до ширины 360px.

## Структура

```
src/
  main.ts               — точка входа
  App.vue               — корневой компонент: шапка, каталог, состояние корзины
  cartStorage.ts        — чтение/запись корзины в localStorage
  formatPrice.ts        — форматирование цены
  data/products.ts      — данные товаров
  components/
    SearchBar.vue       — строка поиска
    ProductCard.vue     — карточка товара в каталоге
    BuyButton.vue       — кнопка «Купить» с состояниями
    ProductModal.vue    — модальное окно товара
    ImageSlider.vue     — слайдер изображений
```

## Примечание

Изображения товаров — SVG-заглушки, сгенерированные для демонстрации (доступа к исходным ассетам макета не было). Дизайн модального окна и состояний кнопки — на своё усмотрение, как указано в задании.
